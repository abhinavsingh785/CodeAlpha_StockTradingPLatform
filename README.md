# Stock Trading Platform

## Description
A Java console-based Stock Trading Platform that allows users to view available stocks, buy and sell shares, and manage their investment portfolio.

## Features
- View Market Data
- Buy Stocks
- Sell Stocks
- View Portfolio
- Balance Management

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- HashMap

## How to Run

```bash
javac Stock.java User.java StockTradingPlatform.java
java StockTradingPlatform
```

## Project Structure

```
Stock.java
User.java
StockTradingPlatform.java
```
